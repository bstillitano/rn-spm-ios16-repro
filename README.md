# SPM autolinking rejects libraries that require iOS 16

Reproducer for [react/react-native#58515](https://github.com/react/react-native/issues/58515).

React Native's SPM autolinker writes the `Autolinked` package with a hardcoded `platforms: [.iOS(.v15)]`. Its `AutolinkedAggregate` target depends on every autolinked library, and SwiftPM won't let a target depend on a product whose package requires a newer platform. So a library that ships its own `Package.swift` declaring iOS 16 can't be autolinked, even when the app itself targets iOS 16.

## What's in this project

`ReproducerApp` is the [React Native reproducer template](https://github.com/react-native-community/reproducer-react-native) (React Native 0.87.1), with these changes:

- Migrated to Swift Package Manager with `npx react-native spm`, which removed the CocoaPods integration.
- The app target's deployment target raised to iOS 16.0.
- One native dependency, [`ios16-library`](ReproducerApp/modules/ios16-library): a stub whose [`ios/Package.swift`](ReproducerApp/modules/ios16-library/ios/Package.swift) declares `platforms: [.iOS(.v16)]`. [`react-native.config.js`](ReproducerApp/react-native.config.js) declares its iOS platform, because the CLI only reports iOS code for packages with a podspec.
- `react-native-safe-area-context` and `@react-native/new-app-screen` removed, since the former ships no `Package.swift` and would stop `npx react-native spm` for an unrelated reason.

## Steps to reproduce

```sh
cd ReproducerApp
yarn install
npx react-native spm update
cd ios
xcodebuild build -project ReproducerApp.xcodeproj -scheme ReproducerApp \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO
```

The [Pre Merge Checks](.github/workflows/pre-merge.yml) workflow runs the same steps, so its iOS job fails the same way.

## Expected

The build succeeds: the app and `ios16-library` both target iOS 16.

## Actual

```
error: The package product 'Ios16Library' requires minimum platform version 16.0 for the iOS platform, but this target supports 15.0 (in target 'AutolinkedAggregate' from project 'Autolinked')
** BUILD FAILED **
```

`ReproducerApp/ios/build/generated/autolinking/Package.swift`, generated by `npx react-native spm update`, contains `platforms: [.iOS(.v15)]`.

## Workaround

In `node_modules/react-native/scripts/spm/generate-spm-autolinking.js`, change the `Autolinked` package's `platforms: [.iOS(.v15)]` to `platforms: [.iOS(.v16)]`, run `npx react-native spm update` again, and build. The build then succeeds.
